Lwkfall

Falling leaves, petals and snow for any website. One canvas, no dependencies, about 7 KB gzipped.

The effect library did not load, so nothing can fall. Extract the whole zip first instead of opening the page from inside it, then run npm run build, or open demo/standalone.html, which needs no other files.
